Политика конфиденциальности

Приложение «fluxprod publisher». Действует с 22 октября 2026 года.

«fluxprod publisher» — личный инструмент для публикации собственных видео в собственные аккаунты владельца канала Sound Flux. Приложение не является публичным сервисом, не регистрирует пользователей и не собирает данные третьих лиц.

Какие данные обрабатываются

  • Токены доступа к платформам (YouTube, TikTok, Instagram), которые выдаёт сама платформа после того, как владелец аккаунта разрешит доступ.
  • Видеофайлы и тексты публикаций, которые владелец сам передаёт приложению.

Где хранятся данные

Все данные хранятся локально на компьютере владельца в папке приложения. Они не передаются на сторонние серверы, не продаются и не используются для аналитики или рекламы.

Что приложение делает с данными

Единственная функция — отправить выбранный владельцем видеофайл и текст публикации в API соответствующей платформы (YouTube Data API, TikTok Content Posting API, Instagram Graph API) от имени владельца аккаунта.

Передача третьим лицам

Данные передаются только тем платформам, куда владелец публикует контент, и только в объёме, необходимом для публикации.

Удаление данных

Владелец может в любой момент отозвать доступ, удалив токены из настроек платформы (Google — «Сторонние приложения», TikTok — «Управление доступом», Meta — «Бизнес-интеграции»), а также удалив файл publish/token.json на своём компьютере.

Дети

Приложение не предназначено для использования детьми и не собирает их данные.

Изменения
