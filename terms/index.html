Условия использования

Приложение «fluxprod publisher». Действует с 22 октября 2026 года.

«fluxprod publisher» — личный инструмент владельца канала Sound Flux для публикации собственных видео в собственные аккаунты на YouTube, TikTok и Instagram.

Назначение

Приложение автоматизирует техническую часть публикации: подготовку вертикального видео, формирование описания и загрузку файла через официальные API платформ.

Кто может пользоваться

Только владелец аккаунта, который сам выдал приложению доступ. Приложение не предоставляет услуг третьим лицам и не публикует чужой контент.

Правила использования

Владелец обязуется:

  • публиковать только собственный контент либо контент, на который у него есть права;
  • соблюдать правила сообществ YouTube, TikTok и Instagram;
  • не использовать приложение для распространения спама, недостоверной информации, материалов, нарушающих авторские права, и контента, запрещённого законом.

Ответственность

Приложение предоставляется «как есть», без гарантий бесперебойной работы. Владелец несёт ответственность за публикуемый контент и за соблюдение правил платформ. Приложение не отвечает за решения платформ по ограничению или удалению публикаций.

Доступ и данные

Приложение хранит токены доступа локально на компьютере владельца. Порядок обработки данных описан в Политике конфиденциальности. Доступ можно отозвать в любой момент в настройках соответствующей платформы.
